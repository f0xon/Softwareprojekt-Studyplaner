# Minimal Viable Project — Flet UI Mockup

Kurze Anleitung, um die UI-Mockup-Oberfläche zu starten:

1. Installiere Abhängigkeiten:

```bash
pip install -r requirements.txt
```

2. Starte die App:

```bash
cd Minimal_viable_Project
python3 flet_app.py
```

Die Oberfläche ist ein reines UI-Scaffold ohne Funktionalität. Die `Todo`-Ansicht zeigt drei einfache Checkboxen: `todo1`, `todo2`, `todo3`.
